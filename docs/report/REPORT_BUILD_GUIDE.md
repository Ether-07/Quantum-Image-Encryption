# Final Report Guide

The numerical results in `report.md` have been populated from the experiment outputs supplied during the final validation stage.

Before submission:

1. Generate the final figures under `docs/figures/`.
2. Insert those figures into the final formatted report.
3. Record the exact hardware/software environment used for the measurements.
4. Perform a clean-environment reproduction test using `requirements.txt`.
5. Review the limitations carefully.
6. Do not change experimental values after the final code is frozen unless the experiment is intentionally rerun.
7. Generate the final PDF/DOCX only after the results and figures are locked.
